# 陪玩伴侣 Companion Chat

一个轻量的 SillyTavern 原生插件：给你的角色扮演/文字冒险加一个悬浮的"陪玩伴侣"聊天窗口，被动地（你主动提问才回复，不打断主线剧情）以旁观者视角陪你聊、点评、答疑。

## 特性

- 常驻悬浮图标，点开是一个独立的聊天窗口（气泡样式），跟主聊天完全分开，不影响、不占用主线上下文。
- 被动模式：不会自动插话，只有你在陪玩伴侣的输入框里主动提问时才会生成回复（走的是静默的旁路生成，不写入主聊天记录）。
- 可选"故事纪要"：填一个世界书条目标题，陪玩伴侣回答时会参考该条目内容（兼容任何把纪要/摘要写进世界书的记忆类脚本，比如社区常见的数据库脚本）。
- 面板可拖拽、位置会记住，视觉完全独立于 SillyTavern 当前主题（不跟随换肤），拖拽不依赖 ST 的"可移动UI"全局设置。
- 人设、显示层数等都可在面板内的 ⚙ 设置里调整。

## 安装

在 SillyTavern 的 扩展 面板里选择"从 URL 安装"，填入本仓库地址：

```
https://github.com/moontale00/st-companion
```

或者手动把本仓库 clone 到 `public/scripts/extensions/third-party/` 下（文件夹名任意，不影响功能）。

## 使用

1. 打开一个角色/对话，点击屏幕右下角的 👁️ 图标展开面板。
2. 在面板底部输入框提问，陪玩伴侣会结合最近几层剧情（默认 2 层，可调）回复。
3. 点 ⚙ 展开设置：调整显示层数、启用故事纪要（世界书条目）、修改人设。

## 当前范围（v0.1.0）

仅实现被动模式。每回合自动点评的主动模式尚未实现，计划在后续版本加入。
